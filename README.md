# Mindfields — playtest build

The live playtest build of **Mindfields**, a grid-based deckbuilder
roguelike about conversations. This repository holds only the built,
single-file game for GitHub Pages delivery — the source, design
documents, and history live in a private repository.

**Play:** https://cumalihaus.github.io/mindfields-playtest/
On iPad: open in Safari → Share → *Add to Home Screen* for the
full-screen app experience.
